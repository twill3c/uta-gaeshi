# uta-gaeshi(歌返し)

**本番: https://uta-gaeshi.vercel.app**

ホメロス『オデュッセイア』全 24 巻・原典 12,107 行を、行番号に固定した日本語で読む。

**同じ行が返ってくる** — 全行の 17.8%(808 種・2,155 回)が他の行の逐語的な繰り返しであることが、
口誦叙事詩としてのこの作品の骨格である。本プロジェクトはそれを全数で示し、同時に
「原典で同一の行は和訳でも同一であるべき」という**非循環の検査**として使う。

和訳は自前の機械生成である。既存の日本語訳は使えない(`data/LICENSE-DATA.md`)。
訳の巧拙は主張せず、生成方法と測定値を開示する。

## 使い方

```bash
python -m pipeline.fetch_tei    # 出典 TEI を取得し sha256 を data/sources.json に刻む
python -m pipeline.parse_tei    # 翻訳単位 data/units.json を構築
python -m pipeline.formulas     # 反復行と定型句 data/formulas.json(目玉)
python -m pipeline.speakers     # 発話定型からの話者候補 data/speakers.json
python -m pipeline.places       # 地名の全数集計 data/places.json
python -m pipeline.align        # 英訳を鍵にした名寄せ data/align.json
python -m pipeline.persons      # 判断表を適用し保存則で検算 data/entities.json
python -m pipeline.build_glossary  # 定型句用語集(巻をまたいで累積)
python -m pipeline.translate       # 和訳の進捗(再開可能な追記台帳)
python -m pipeline.site         # 静的サイトを out/ へ生成(29頁)
python -m pipeline.sitegates    # G-15 リンク整合 / G-16 外部依存ゼロ / G-17 権利表示
python -m pytest -q             # 構造ゲート・測定の不変量・陽性対照
```

## L2 で測れたこと

| 測定 | 値 |
|---|---|
| 逐語的に反復する行 | 808 種 / 2,155 回 = **全行の 17.8%**(全群が単位を跨ぐ) |
| 和訳の強制等値制約 | **1,347 件**(原典で同一の行は和訳でも同一であるべき) |
| 定型句(5 回以上) | 3-gram 644 種 / 4-gram 320 種 / 5-gram 192 種 |
| 発話導入定型 | 611 行(全行の 5.1%)。うち固有名詞を伴う 364 行(60%) |
| 話者候補 / 受け手候補 | 35 / 14。父称と判定 14、格が曖昧で判定保留 18 |
| 地名タグ | 418 箇所 / 異なりキー 70(tgn 49・perseus 21) |
| 同一表記が複数キーに分裂 | 5 件(Troy は **3 キー**、Ithaca / Pylos / Olympus / Elis が各 2) |
| 航海の寄港地のタグ | 10 件中 **9 件がタグ無し**(Scheria のみ有り) |

最後の行が企画の芯である。寄港地は本文に現れるのに典拠データに存在しない。
稀だからではなく指示対象が無いためであり、**オデュッセウスの航路は地図に描けない**。
描けない区間を明示することを地図の仕様とする。

`data/raw/` は git 管理外(再取得可能)。上流が改訂されると `tests/test_pins.py` だけが落ちる。
そのときは実測し直して `pipeline/pins.py` と `pipeline/gates.py` を更新する。

## L3 で決めたこと

名寄せの同一性の鍵は**無変化な英訳側**に置く。ギリシャ語の語幹を鍵にすると、
別人の過剰併合(`ευρυ` ← Εὐρύκλεια / Εὐρύμαχος / Εὐρύλοχος)と、補充形の分断
(Ζεύς / Διός が繋がらない)が同時に起き、しかもどちらも例外にならない。
英訳を鍵に替えた途端、280 表層形中 245(88%)が自動確定した。

| 判断 | 内容 |
|---|---|
| 人手確認の範囲 | 出現 10 回以上の人物 + 地名 + 集団 = 62 実体。残り 49 実体と保留 35 形は**未確認と明示して出す** |
| 父称の扱い | 指示先が一意なものだけ解決(Κρονίων→ゼウス、Λαερτιάδης→オデュッセウス)。Ἀτρεΐδης はアガメムノンとメネラオスの両方がありうるため**保留**し、文脈判定はしない |
| 地名の段 | tier1 同定確実 15 / tier2 比定に争いあり 3 / tier3 同定不能 7 / 神話的空間 2 |

判断は `data/judgments/` に表として持ち、コードに埋めない。各項に根拠を書く。

人手確認は実際に機械の誤りを捕まえた — ゼウスにメネラオスの呼格とヘラが、
オデュッセウスにアルキノオスの与格と地名が付着していた。ラエルテスは
Perseus の地名タグの巻き添えで地名に分類されていた。

## L4 で決めたこと

和訳の方針は全 2,432 単位に一貫適用され、後からの変更は全訳し直しになる。

| 判断 | 内容 |
|---|---|
| 文体 | 平明な現代語散文 |
| 定型句の反復 | **中核句は一字一句同一、前後の助詞・接続のみ可変**。G-02 は中核句の包含で判定 |
| 中核句の書き方 | **活用しない部分に限る**(名詞句・形容辞)。動詞の終止形で終わらせない |

中核句を活用形で終わらせない規則は、最初の版の失敗から来ている。節ごと中核句にしたところ
94 件中 49 件が活用語尾で終わり、実際に落ちた(「…我が家へ帰る」が訳文では「…帰り着く」)。
ホメロスの定型句を定型句たらしめているのは形容辞であって節全体ではない。
**確実に検査できる弱い制約のほうが、ランダムに落ちる強い制約よりよい。**

## 和訳の進め方

`data/translated.jsonl` は**追記のみの台帳**で、同一 id は最後の行が有効。
一度訳した単位を二度と訳し直さないことを前提に設計してある。
用語集や判断表を改訂したら `recheck()` で全件を測り直す。

第 1 巻に現れる反復行 94 種は**すべて他巻へ波及する**ため、第 1 巻を訳した時点で
残り 23 巻の骨格が決まっている。

## 用語集は巻をまたいで累積する

一度入った中核句は以後のすべての巻を拘束する。現在 625 件。
既存の用語集で足りた割合は単調には上がらない。第7巻の 56% のあと、
第9巻は 31% まで落ちた。累積は「進むほど楽になる」性質のものではない。

**この落ち込みを一度は「語りの切れ目で落ちる」と説明したが、外れた。**
第9巻でオデュッセウスの一人称の語りが始まったことに原因を求め、
であれば語りが三人称の枠物語へ戻る第13巻でも落ちるはずだと予測した。
実測は 79% で最高値。予測は反証された。

出どころを数え直すと理由が出た。**第13巻の充足 48 件のうち 81% が
第1〜8巻由来**である(第12巻は 63% が放浪譚由来だった)。第13巻は
イタケ帰着・宮廷・船出という、第1〜8巻がすでに厚く在庫を作った
場面へ戻る巻なのだ。つまり効いているのは語り手ではなく**場面の種類**である。
第9巻が落ちたのも、一人称になったからではなく、
**在庫のない場面(単独の航海・怪物・上陸)に入ったから**と読むほうが合う。

**その言い直しからさらに一度外した。** 「第14巻以降はイタケの場面が
続くので高いまま」と述べたが、実測 47%。豚飼いの小屋は宮廷とは別の場面型で、
家畜・粗末な饗応・乞食の作り話という新しい在庫が要る。仮説は事後には
説明できてしまうが、それは反省したばかりの事後当てはめである。

そこで**残り 10 巻の予測を訳す前に一度に固定した**。
`data/judgments/coverage_predictions.json` に high/medium/low の band で登録し、
band を書き換えられないようテストで刻印してある。実測はループログにだけ記録し、
予測表は動かさない。10 巻を終えた時点で的中率を数え、**半分以上外れたら
場面型という説明も捨てる**。

**一件目(第15巻)は外れた。** 予測 medium に対し実測 80%(high)。
第14巻で小屋の場面に払った中核句 39 件が即座に効いたためで、
見積もりが保守的すぎた。的中率 0/1。予測表は書き換えない。
